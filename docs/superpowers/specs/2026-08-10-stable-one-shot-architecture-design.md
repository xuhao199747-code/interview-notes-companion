# 稳定版一次性识别架构

## 目标

将产品收敛为一条可靠链路：候选人按“识别问题”按钮或全局快捷键开始录题，停顿后自动提交，或再次按按钮/快捷键立即提交；随后执行术语归一、资料检索与 LLM 流式回答。

## 保留能力

- Markdown 资料库、回答 Skill、回答规则与术语表的上传、编辑、删除、下载和本机持久化。
- 豆包或腾讯云 ASR 的一次性录题会话。
- 可配置、可持久化的全局组合快捷键。
- 项目范围识别、严格资料召回、LLM 回答范围控制、上一题查看。
- LLM API 配置与流式回答。

## 删除范围

- 全程监听、桌面持续录音、浏览器 `SpeechRecognition` 监听。
- 自动按说话人过滤、腾讯云声纹、本地声纹模型、声纹录入/验证/档案管理。
- “监听方式”和“本人声纹过滤”设置页面、其 IPC、HTTP API、状态与样式。
- 为旧监听链路保留的 ASR 临时状态、音频窗口、声纹音频缓存、旧快捷键提交模式。
- 未使用的 `electron/preload.js`；运行时只保留 `electron/preload.cjs`。

删除前会保留既有资料、Skill、术语表、回答规则、ASR 与 LLM 配置；仅清除已废弃声纹与全程监听相关配置。

## 目标目录

```text
renderer/
  bootstrap.js                 # 启动与依赖装配
  features/
    question-capture/          # 一次性录题、静默提交、快捷键
    answer/                    # 当前题、上一题、检索与生成展示
    documents/                 # 文档、Skill、术语、规则管理
    settings/                  # ASR、LLM、快捷键配置
  ui/                          # DOM 查询、下载、通用渲染
core/
  question/                    # 问题清洗、断句、术语归一
  retrieval/                   # 解析、召回、重排、项目上下文
  answer/                      # 路由、上下文、LLM 请求
  storage/                     # 配置、文档与规则存储
desktop/
  main.js                      # 窗口、一次性 ASR、全局快捷键
  preload.cjs                  # 最小 IPC 桥接
server/
  handlers/                    # documents / retrieval / answer / config
tests/
  unit/ api/ electron/         # 关键行为契约与冒烟验证
```

首次迁移不追求一次性移动全部文件：先移除旧链路并将 `app.js` 拆为功能入口，纯逻辑模块再按领域归类，避免重构时改变行为。

## 边界与验证

1. 页面只显示一个“识别问题”入口；再次点击或再次按快捷键立即提交。
2. Electron 主进程仅维护一个 ASR 会话和一个全局识别快捷键。
3. 所有关键配置只存在一个字段、一个设置入口、一个持久化写入点。
4. 无关资料不得因关键词命中被送入 LLM；无可靠资料显示空状态。
5. 上传、删除、下载、保存快捷键、录题、提交和生成必须有行为测试，不能仅用源码文字匹配测试。
