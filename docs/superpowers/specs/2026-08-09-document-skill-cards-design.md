# 文档与 Skill 管理卡片设计

## 目标

在设置页以统一的小卡片管理上传的资料和回答 Skill，使用户能添加、编辑、删除文件，并一眼看到正在使用的 Skill。

## 交互

- 资料管理保留现有上传入口；每份资料以卡片展示类型标识、文件名、章节数和字数，右侧提供“编辑”和“删除”。
- 回答 Skill 使用与资料相同的卡片样式；卡片显示 `SK`、文件名、`回答 Skill`，当前生效的卡片额外显示“当前应用中”。
- Skill 页保留上传入口；上传的 Skill 自动成为当前应用项并新增为一张卡片。
- 删除资料后，资料立即从本地保存和检索索引中移除。
- 删除当前 Skill 后，自动切换到剩余 Skill 中的一个；若没有剩余 Skill，恢复内置默认回答规则。

## 范围

仅改设置页的资料与 Skill 管理展示和交互；不改变文件解析、LLM 请求格式或现有保存格式。

## 验证

- HTML 测试覆盖 Skill 卡片容器、当前应用状态和编辑/删除操作入口。
- 现有资料上传类型和 Skill 选择测试继续通过。
