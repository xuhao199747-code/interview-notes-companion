# 面试资料伴侣 UI 组件规范

## 目标

将现有桌面端界面统一为“深灰底 + 紫色强调”的视觉系统，避免同一类组件出现不同的卡片层级、按钮形态、边距和滚动行为。此规范只定义 UI 边界与样式规则；不改变语音识别、检索、LLM、文件持久化等业务逻辑。

## 适用范围

- 问题识别与回答浮层。
- 设置页：资料管理、回答 Skill、回答规则、术语表、语音识别、LLM API。
- 文件卡片、上传入口、设置卡片、空状态、弹窗与历史回答弹层。

## 视觉基础

### 颜色 Token

| Token | 值 | 用途 |
| --- | --- | --- |
| `--ui-surface` | `#252526` | 页面、主要面板背景 |
| `--ui-surface-raised` | `#2b2d31` | 卡片、设置块、次级容器背景 |
| `--ui-control` | `#1e1f22` | 输入框、次按钮、浮层控制背景 |
| `--ui-border` | `#3c3f41` | 默认边框和分隔线 |
| `--ui-text` | `#f0f0f0` | 主文字 |
| `--ui-muted` | `#a0a0a0` | 辅助文字、说明文字 |
| `--ui-accent` | `#a78bfa` | 主强调色、选中态、焦点态 |
| `--ui-accent-soft` | `rgba(167,139,250,.14)` | Hover、选中背景 |
| `--ui-warning` | `#d7ba7d` | 仅用于风险/注意提示 |
| `--ui-danger` | `#ff8c8c` | 删除与不可逆操作的 Hover |

不再新增绿色强调色作为主交互状态；既有绿色仅在历史内容中逐步替换，新的组件必须使用紫色 `--ui-accent`。

### 字体与层级

- 默认字体：`Manrope, -apple-system, BlinkMacSystemFont, "PingFang SC", sans-serif`。
- 中文正文：14px / 1.75；浮层正文：14px / 1.75；不将正文缩小到 12px 以下。
- 页面标题：28px，字重 700；设置模块标题：20px，字重 700；卡片标题：15px，字重 650。
- 标识/标签：11px，字重 600；仅在必要时使用等宽字体，避免用英文装饰性标签替代实际中文标题。
- 同一块内容最多保留“标题 + 辅助说明 + 正文”三级，删除重复的英文标题和装饰性副标题。

## 布局与间距

### 尺寸 Token

| Token | 值 | 使用场景 |
| --- | --- | --- |
| `--space-1` | 6px | 控件内紧凑间距 |
| `--space-2` | 10px | 同一卡片内项目间距 |
| `--space-3` | 16px | 卡片内区块、双列间距 |
| `--space-4` | 24px | 页面内容边距、模块间距 |
| `--radius-control` | 6px | 按钮、输入框 |
| `--radius-card` | 8px | 文件卡、设置卡 |
| `--radius-panel` | 12px | 主面板、弹窗、浮层 |

- 桌面主页面左右内边距固定为 24px；窄窗口降为 12px。
- 设置页标题区固定在顶部，只有 `.settings-scroll-content` 负责纵向滚动。
- 回答页面自身不滚动；左侧文档参考和右侧 LLM 回答各自的内容区独立滚动。
- 禁止为某个页面单独增加大于 32px 的无内容留白；所有空白必须来自上述间距 Token。

## 组件规范

### 1. 顶部导航与 Tab

- 顶部导航仅承载“问题 / 设置”一级切换。
- 设置 Tab 承载二级功能切换；默认背景透明，选中态为 `--ui-accent-soft`，文字和下边框均为 `--ui-accent`。
- Tab 高度 40px，水平内边距 14px；不可用橙色焦点框作为常态视觉。
- Tab 数量增加时优先横向滚动或缩小间距，不允许挤压、折行或溢出页面。

### 2. 主面板与双列回答区

- 主面板：`background: --ui-surface`、1px `--ui-border`、12px 圆角。
- 回答区只有两列：`文档库参考` 与 `LLM 生成回答`；两列标题、边距、背景、滚动方式必须相同。
- 不增加“LLM GENERATED”“AI GENERATED”等重复英文装饰，也不添加额外橙色内框。
- 无内容时两列都使用同一种空状态：图标、短句、可选辅助说明；不得保留上一题内容。
- “上一题”只能通过单独的浮动操作打开历史，不占用当前题的回答区高度。

### 3. 文件卡片

资料、回答 Skill、回答规则、AI 术语表、产品经理术语表均使用同一个文件卡片结构：

```
[ 文件类型徽标 ]  文件名
                  类型 · 章节/字数 · 状态
                  下载 ｜ 删除
```

- 卡片背景 `--ui-surface-raised`，8px 圆角，1px `--ui-border`。
- 徽标固定 40px × 40px；文件名单行省略；元信息一行省略。
- 操作一律是右侧文字按钮，顺序固定“下载｜删除”。
- 下载为中性色 Hover 变紫；删除平时中性色，Hover 变 `--ui-danger`。
- 强制保留的默认回答规则不显示“删除”；需要恢复时，提供明确的“恢复默认规则”，避免将删除实现为隐式重置。
- 上传空卡与已上传文件卡占同一网格位置、同一高度，不因状态切换导致页面跳动。

### 4. 按钮

| 类型 | 外观 | 场景 |
| --- | --- | --- |
| 主按钮 `.primary-button` | 紫色实底、深色文字 | 上传、保存、确认识别 |
| 次按钮 `.secondary-button` | 深色底、灰边框 | 测试连接、取消、辅助操作 |
| 浮层操作 `.overlay-action` | 深色半透明底、灰边框 | 识别问题、上一题、置顶、设置 |
| 文字操作 | 无底色、无边框 | 下载、删除、编辑 |

- 所有按钮圆角使用 `--radius-control`，不能混用 6px、7px、8px 等无意义差异。
- 控件高度统一 40px；设置页小型文字按钮可为 32px。
- 图标按钮必须为 40px × 40px，图标居中，不将文字基线作为居中依据。
- 禁止把删除操作伪装成主按钮；任何不可逆操作均需要确认提示。

### 5. 输入框与选择器

- 背景 `--ui-control`，1px `--ui-border`，6px 圆角，最小高度 40px。
- Focus 仅使用紫色边框和轻微紫色阴影；不使用亮绿色或橙色大描边。
- 密钥字段只显示掩码与“已保存”状态，绝不回显原文。
- 只读快捷键输入框必须在视觉上标明“点击后录入组合键”，不可让用户误以为可直接键入文本。

### 6. 设置页卡片与说明

- 设置项使用 `listening-config-card` 同类的次级卡片：8px 圆角、16px 内边距、无固定最小高度。
- 说明文案紧跟标题，使用 `--ui-muted`；警告仅在真实配置风险时展示。
- 同一屏内不要重复“已保存到本机”等提示；保存状态统一放在操作区下方一行。

### 7. 浮层、弹窗与覆盖层

- 识别工具栏和回答浮层属于同一 `#answerOverlay`，使用同一半透明深灰背景、12px 圆角、统一边框。
- 浮层展开后，工具栏保持固定，正文区域独立滚动；窗口切换、拖动不应改变视觉尺寸。
- 弹窗遮罩为半透明黑色 + 可选 blur，弹窗本体使用 `--ui-surface`，12px 圆角。
- 浮层/弹窗只允许一个高层 z-index 体系：遮罩 < 浮层内容 < 浮层操作；禁止新增任意魔法数覆盖现有层级。

### 8. 空状态、加载与反馈

- 空状态文案采用“当前状态 + 下一步”两行以内，例如“文档库没有直接匹配 / 可使用识别问题重新录入”。
- 加载中仅显示一个稳定状态，不显示“音频包数量”等工程调试信息。
- 错误必须说明动作与可执行下一步，例如“语音服务连接失败，请检查 Access Token 后重试”。
- 页面状态不得依赖闪烁、反复替换文本或自动滚动表达。

## CSS 架构约束

### 文件职责

- `styles.css`：全局 Token、基础排版、通用按钮、卡片、Tab、空状态。
- `config.css`：设置页布局、问题工作区、回答浮层与响应式规则；不得重新定义基础按钮/卡片颜色。
- `modal.css`：仅编辑弹窗的布局与局部控件。

### 禁止规则

1. 不在文件末尾通过重复选择器覆盖同一个组件的核心颜色、圆角或间距。
2. 不新增 `!important`；已有 `!important` 仅在浮层防选中文字的必要场景保留，并在重构时收敛。
3. 不为相同组件创建多个近义 class（例如新的 `*-button`）来绕开现有按钮规范。
4. 不以绝对定位修复普通页面布局；绝对定位仅用于浮层、遮罩与明确的悬浮操作。
5. 不把业务状态文案、语音包数量、调试字段作为常态 UI 内容。

## 验收清单

- [ ] 所有文件卡片的高度、徽标、元信息和“下载｜删除”文字操作一致。
- [ ] 资料与回答两列的标题和内容层级一致；仅内容区滚动。
- [ ] 所有主/次/文字/图标按钮符合固定样式和尺寸。
- [ ] 设置页固定标题与 Tab，内容单独滚动，窄窗口不溢出。
- [ ] 不再出现绿色主交互、橙色装饰框、重复英文标题。
- [ ] CSS 的全局 Token 与组件基础样式只在一个来源定义，其他文件只写对应页面布局。

## 后续落地顺序

1. 先建立共享 Token 与通用组件基类，移除重复覆盖。
2. 统一文件卡片和设置页 Tab，再统一回答双列和空状态。
3. 最后收敛悬浮答题工具栏、历史弹窗与响应式样式。
4. 每一步仅改 UI，并使用截图/界面测试确认不影响语音、检索、生成及本地数据。
