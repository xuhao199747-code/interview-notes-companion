# 极简术语表上传设计

## 目标

将“术语与项目上下文”设置页改为只服务术语表上传：用户上传一个 Markdown 文件后，应用自动解析并立即用于问题归一化；页面仅显示当前文件名和已应用状态。

## 范围

- 保留现有 Markdown 解析、localStorage 持久化与检索前术语归一化逻辑。
- 移除项目范围下拉框、项目自动识别状态、Markdown 格式说明、内置术语标题和术语条目列表。
- 初始状态显示“尚未上传术语表”。
- 上传并成功解析后显示“文件名（已自动应用）”。
- 上传文件没有可识别术语时，保留清晰的错误提示，且不替换已生效的术语表。

## 界面与数据流

设置页只保留“术语表”标题、简短说明、上传按钮和文件状态。文件选择后，前端读取 Markdown，调用现有解析函数；解析成功则替换内存中的 glossary，并保存术语数据及文件名到 localStorage。之后每次检索继续使用该 glossary 自动归一化问题。

## 验收标准

1. 页面没有项目选择控件、格式示例或术语条目列表。
2. 成功上传后，页面显示上传文件的文件名及“已自动应用”。
3. 已存在的 Markdown 术语解析与问题归一化测试继续通过。
4. 新测试覆盖文件名状态的显示文案。
