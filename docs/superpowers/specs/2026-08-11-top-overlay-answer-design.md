# 顶部半透明答题浮层设计

## 目标

将问题页改为始终位于窗口顶部中间的半透明答题浮层。默认只展示实时转写与“识别问题”控制；确认问题后立即展示文档参考与 LLM 生成结果。

## 状态

1. 空闲：仅显示控制条和识别按钮。
2. 录音中：控制条实时显示转写文本和识别中状态。
3. 生成中：确认题目后立即展开回答区；文档结果立刻展示，LLM 区展示生成中并流式更新。
4. 当前题：文档与 LLM 两列内容均可查看，卡片内部独立滚动。
5. 历史题：点击“上一题”后，浮层主体替换为最近一题；控制条保留，支持返回当前题或直接开始新识别。

## 交互规则

- 点击浮层外的半透明背景或收起图标，收起回答主体，保留顶部控制条和历史入口。
- 点击收起状态下的图标重新展开当前题。
- 新题确认前，原当前题不变；新题确认后，原当前题成为最近一题，旧题的 LLM 请求不再更新界面。
- 历史题查看时开始识别新题，会退出历史视图进入实时转写；新题确认后按同一替换规则保存当前题。
- “上一题”仅保存最近一道完整题，入口固定在控制条旁。

## 视觉约束

- 浮层顶部居中、半透明并带背景模糊，能看到会议窗口内容。
- 两列标题只使用中文：文档库参考、LLM 生成回答。
- 浮层外点击区域仅在回答主体展开时出现。
- 窄窗口保持单列内容与可读的控制条。
- 视觉层级限制为两层：透明桌面背景与单一答题工作面板；不使用全屏深色遮罩或额外的外层卡片阴影。
- 顶部工具栏与展开后的回答区属于同一工作面板，使用同一条细边框、圆角和间距体系。
- 文档库参考与 LLM 生成回答是同级同样式的两列：相同标题、内边距和独立正文滚动；它们在同一内层工作面板中用细分隔线区分，不再各自叠加背景卡片。
- 普通控制按钮使用统一的深灰实底、36px 高度和细边框；荧光绿色仅用于正在识别、激活和关键状态，不作为普通按钮底色。

## 非目标

- 不改变检索、语音、LLM 请求、保存资料或声纹功能。
- 不增加多题历史列表；仅保留最近一题。
