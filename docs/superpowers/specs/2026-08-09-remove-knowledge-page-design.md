# 移除独立知识库页面

## 目标

将资料管理统一到“设置 → 资料管理”，移除重复的独立“知识库”导航入口和页面。

## 范围

- 删除顶部导航中的“知识库”按钮。
- 删除仅由该按钮打开的 `knowledgeView` 页面及其上传控件。
- 保留设置页的“资料管理”面板、资料上传/编辑/删除能力，以及首页基于资料的检索和回答功能。
- 应用启动时仍默认显示首页；不再存在跳转到独立知识库页的代码路径。

## 数据与兼容性

本次不更改 localStorage 中的资料、Skill 或删除记录键，因此已保存资料继续可用。

## 验证

- 自动化检查页面中不再有 `knowledgeView` 和 `data-view="knowledgeView"`。
- 自动化检查“资料管理”设置面板仍保留。
- 运行现有资料检索相关测试，确保搜索逻辑不受影响。
