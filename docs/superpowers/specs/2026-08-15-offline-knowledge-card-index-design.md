# 离线知识卡索引设计

## 目标

用户可以继续上传混合的 Markdown 资料。应用在资料保存时自动拆分和标注内部知识卡；面试提问时仅对已准备好的卡进行项目过滤、混合召回与一次本地重排，优先保证速度和不答非所问。

## 不变项

- 原始 Markdown 的内容、文件名、下载、编辑与删除能力保持不变。
- 已保存的资料、术语表、LLM 与语音配置不迁移、不删除。
- 实时问答不调用 LLM 来拆卡、分类或重排。

## 离线入库

资料上传后，Markdown 继续按标题和正文切分。每个切片会得到内部知识卡元数据：稳定卡片 ID、所属项目、角色（个人经历/项目方案/项目指标/复盘/通用）、标题别名和检索文本。标题、项目名、别名和正文共同用于词面和向量索引。原始资料仍是用户可见的唯一源文件。

## 在线问答

1. 对 ASR 最终问题应用术语归一化。
2. 使用既有项目上下文确定候选资料范围。
3. 并行获得词面候选和语义候选；两路候选均可进入候选池。
4. 采用 Reciprocal Rank Fusion 合并候选；标题/别名精确命中可获得有限加分。
5. 对 Top 12 做本地确定性重排，优先问题标题、项目、意图和技术词一致的卡。
6. 路由层只在可靠命中时使用资料；否则保留现有空状态/通用生成策略。

## 性能边界

- 上传或资料修改时建卡和生成文档向量；问题阶段只计算一个查询向量。
- 不在问题阶段加载整篇 Markdown、调用 LLM 拆卡或对全库做重排。
- 一次本地排序仅作用于最多 12 个候选，不能阻塞 LLM 首字流式输出。

## 验证

- 自动测试覆盖：混合资料自动形成项目与通用卡、别名参与召回、词面和语义候选都保留、RRF 对精确题目优先、错误项目不因泛词被带入。
- 对现有项目资料运行现有检索测试，保证自我介绍、RAG、Agent、指标等回归题保持正确。
