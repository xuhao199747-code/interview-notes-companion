# 双来源回答与上一题保留设计

## 目标

让面试回答区同时提供文档库命中内容和 LLM 自动生成内容，并在语音识别被打断、片段不完整或生成失败时保留可回看的上一题完整答案。

## 页面与交互

- 回答区分为两个并列面板：`文档库参考` 与 `LLM 生成回答`。
- 每个确认的问题自动触发两条路径：立即检索文档库，并异步请求 LLM。
- 回答区顶部始终显示默认展开的 `上一题` 卡片，包含问题、文档库结果和 LLM 结果。
- 只有一个新问题被确认后，当前题完整快照才写入上一题；实时转写、空文本、过短片段、生成报错均不可清空或覆盖上一题。
- LLM 请求采用递增请求编号。旧问题的请求即使晚返回，也不能覆盖当前题。

## 问题确认规则

- 实时语音仅更新转写显示。
- 明确以问号结束的最终语音立即确认；其他最终语音等待 1 秒静默后确认。少于 4 个字符的片段视为不完整，忽略。
- 未确认期间实时展示文档库候选，LLM 仅在问题确认后请求。
- 手动输入可直接确认问题。
- 已确认问题用一个状态快照保存：`question`、`documentHtml`、`llmHtml` 和 `llmStatus`。

## Skill 与资料管理

- `回答 Skill` 页提供唯一的 Skill Markdown 上传入口。
- 资料管理只允许选择 `逐字稿` 或 `知识库`，不再显示 Skill 类型。
- 上传 Skill 后更新当前回答规则；现有 Skill 仍可在资料列表中编辑或删除。

## 测试

- 纯状态模块负责问题可确认性、上一题归档和延迟 LLM 结果的请求编号保护。
- 测试覆盖：短片段不覆盖、完整新问题归档、过时 LLM 结果被拒绝、当前 LLM 结果被接受。
