## 目标

## 固定题目模板

```markdown
## 问题标题（可能问法 A / 可能问法 B）

**关键词：** …
**适用场景：** …
**回答：** …

**背景：** …
**具体做法：**
1. …

**结果：** …

**追问补充：**
- …
```

## 内容规则

- 回答先给结论，再讲背景、方法、结果；保持第一人称、可口述的表达。
- 只使用原始材料中已有的事实与指标；未确认项明确标注为“待确认”或描述为方案，不编造成果。
- 同一事实只在最相关的问题中展开，其他问题用简短交叉提示，避免重复和口径冲突。
- 将技术名词还原为业务决策：说明为什么选、如何验证、失败如何降级。
- 保留对面试有价值的追问，不保留原文的草稿提醒、无关画板占位或冗长过程表。

### GEO 品牌增长平台

自我介绍、AI 产品经理职责、RAG、Agent、MCP、Skill、评测、成本与稳定性、项目复盘方法。

## 验收标准

- 每题完整包含固定模板的六个字段。
- GEO 与旅游项目的高频面试主题均有独立题目。
- 数字、范围与上线状态与源材料一致。
- Markdown 无飞书残留标签，标题层级正确，可在常见编辑器直接阅读。
