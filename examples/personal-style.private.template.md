# 本机个人表达偏好（空白模板）

> 这是公开仓库提供的参考模板。可将内容复制到本机的“回答规则”文件中；该文件由桌面应用保存在本机，不能提交到 GitHub。
>
> 这是可选文件。它只描述表达习惯，不提供项目事实；不填写也不影响知识库检索和回答。

## 回答节奏

- 默认首答长度：例如 30—60 秒。
- 复杂问题：例如先给结论，再补两到三点依据。
- 追问：例如优先直接回答追问，不重复上一题全文。

## 口语偏好

- 希望使用的表达：例如“我会先……”或“我的判断是……”。
- 希望避免的表达：例如机械标题、过度客套、过长铺垫。
- 技术术语：首次出现时保留英文并补充中文解释。

## 严禁写入本文件

不要填写姓名、公司、项目名、真实指标或客户信息；这些内容只放在“资料管理”的本机 Markdown 中。
