# 面试资料伴侣

> 本地优先的 macOS 面试资料辅助工具：把 Markdown 资料、术语表和回答规则组织在本机，在需要时用一次性语音识别问题，快速检索资料并生成口述参考答案。

![Platform](https://img.shields.io/badge/platform-macOS-black?logo=apple) ![Runtime](https://img.shields.io/badge/runtime-Electron-47848F?logo=electron) ![Data](https://img.shields.io/badge/data-local--first-7c3aed)

它适合已经自行整理了面试资料、希望在授权可读稿或练习场景中快速定位内容的人。项目不会提供或上传任何默认的个人简历、项目经历、逐字稿或服务密钥；这些内容由每个使用者在本机自行导入和管理。

## 能做什么

- 导入、编辑、下载和删除本地 Markdown 知识库。
- 分别管理回答 Skill、回答规则、产品术语表和资料转换 Skill。
- 使用“识别问题”按钮或自定义全局组合快捷键，完成一次完整问题的录音与转写。
- 先展示本地资料命中；没有可靠命中时明确显示空状态，再按你的规则调用兼容 OpenAI Chat Completions 的 LLM。
- 支持浏览器、豆包等语音识别服务配置；密钥仅保存在本机。
- 一键导出或导入本地资料备份，便于迁移、重装和版本升级。

当前版本采用一次性问题识别，不包含全程监听、声纹过滤或自动判断说话人功能。

## 数据与隐私

- 桌面版资料、术语表、规则、服务配置和快捷键都保存在 Electron 的 `userData` 目录，不依赖源码目录。
- API Key、Token 和语音服务凭据仅存本机，不会在界面回显，也不会进入导出备份。
- “上传资料”仅新增资料文件；“导入备份”用于恢复资料库、术语表、回答规则和偏好设置。
- 本仓库只提供通用代码与模板。个人资料、项目原文、简历、逐字稿、个人回答 Skill 和本地配置均不应提交。

提交前请自行检查：个人资料、项目原文、简历、逐字稿、API Key、Token 与本机导出备份均不得进入 Git。

## 启动

```bash
npm install
npm run desktop
```

开发时可运行：

```bash
npm start
```

## 打包 macOS 应用

```bash
npm run package:mac
```

产物位于 `release/mac-arm64/面试资料伴侣.app`。升级时请使用新版本替换应用本体；用户已配置的本机资料和密钥不会随源码目录一起打包。

## 开发检查

```bash
npm test
```

发布前请至少完成一次启动验证、一次资料导入验证，以及一次空资料状态验证。

## 开源边界

仓库中的 `assets/` 仅应放通用规则或空白模板；你个人使用的回答 Skill、项目知识库和术语表应留在本机，通过应用的“设置”页面导入。这样既不会影响本地检索与生成效果，也能让其他人下载开源版本后填入自己的资料。
