# 面试资料伴侣

本地优先的 macOS 面试资料辅助工具。导入 Markdown 资料后，使用一次性“识别问题”录音，将完整问题转写、检索本地资料，并在需要时调用用户自行配置的 LLM 生成口述参考答案。

## 当前工作方式

1. 在“设置”中导入知识库、回答 Skill、回答规则和术语表。
2. 配置豆包、腾讯云或浏览器语音识别；可选配置兼容 OpenAI Chat Completions 的 LLM。
3. 点击“识别问题”或按已设置的全局组合快捷键，复述问题。
4. 停顿 3 秒自动提交，也可再次点击立即提交。
5. 左侧显示本地资料命中，右侧显示 LLM 参考回答；没有可靠命中时左侧明确显示空状态。

产品不再包含全程监听、声纹过滤或自动判断说话人功能。

## 本地数据与隐私

- 桌面版资料、术语表、规则、服务配置和快捷键都保存在 Electron 的 `userData` 目录，不依赖源码目录。
- API Key 仅存本机配置，不会在界面回显。
- 导出的 Markdown 由用户主动下载；项目不会自动上传资料。

## 启动

```bash
npm install
npm run desktop
```

开发时可运行：

```bash
npm start
```
